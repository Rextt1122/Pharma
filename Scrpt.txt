[2] MENJALANKAN FASTAPI
--------------------------------------------------------------------------------

A. Otomatis via Docker 

   docker restart pbl_backend

   # Cek log:
   docker logs -f pbl_backend

B. Manual via Terminal VM

   # 1. Hentikan container Docker dulu agar port 8001 tidak bentrok:
   docker stop pbl_backend

   # 2. Masuk folder backend & jalankan uvicorn:
   cd /home/fabian/pbl-project/backend
   uvicorn main:app --host 0.0.0.0 --port 8001 --reload

   # Catatan: Tekan Ctrl + C untuk keluar dari uvicorn, lalu nyalakan docker lagi:
   docker start pbl_backend
