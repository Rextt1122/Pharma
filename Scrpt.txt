[1] KONEKSI SSH KE VM (Dari PowerShell Laptop)
--------------------------------------------------------------------------------
ssh root@192.168.33.10


[2] MENJALANKAN FASTAPI (PILIH SALAH SATU)
--------------------------------------------------------------------------------
A. Otomatis via Docker (Latar Belakang / Default):
   docker restart pbl_backend
   # Cek log:
   docker logs -f pbl_backend

B. Manual via Terminal VM (Untuk Demo / Presentasi Kodingan):
   # 1. Hentikan container Docker dulu agar port 8001 tidak bentrok:
   docker stop pbl_backend

   # 2. Masuk folder backend & jalankan uvicorn:
   cd /home/fabian/pbl-project/backend
   uvicorn main:app --host 0.0.0.0 --port 8001 --reload

   # Catatan: Tekan Ctrl + C untuk keluar dari uvicorn, lalu nyalakan docker lagi:
   docker start pbl_backend


[3] MENYALAKAN DOCKER-COMPOSE (BACKEND, DATABASE, MQTT, BACKUP)
--------------------------------------------------------------------------------
cd /home/fabian/pbl-project
docker compose up -d

# Cek semua container aktif:
docker ps

# Restart semua container aplikasi:
docker compose restart

# Hentikan semua container aplikasi:
docker compose down


[4] MENYALAKAN 3 DOCKER ENGINE TAMBAHAN (DIND AGAR PORTAINER HIJAU SEMUA)
--------------------------------------------------------------------------------
# Jalankan ketiga engine Docker-in-Docker:
docker run --privileged -d --name docker-node2 --restart=always -p 2376:2375 -e DOCKER_TLS_CERTDIR="" docker:dind --tls=false
docker run --privileged -d --name docker-node3 --restart=always -p 2377:2375 -e DOCKER_TLS_CERTDIR="" docker:dind --tls=false
docker run --privileged -d --name docker-node4 --restart=always -p 2378:2375 -e DOCKER_TLS_CERTDIR="" docker:dind --tls=false

# Refresh / Restart Portainer agar mendeteksi status UP:
docker restart portainer


[5] PERINTAH DATABASE MYSQL
--------------------------------------------------------------------------------
A. Cara Masuk Normal / Interaktif (Ketik Password Sendiri):
   # 1. Di terminal VM, ketik perintah ini lalu Enter:
   mysql -h 127.0.0.1 -u root -p pbl_db

   # 2. Saat muncul "Enter password:", ketik:
   passwordkuat123
   (catatan: saat ketik password, teks memang tidak tampil/blank demi keamanan, langsung tekan Enter saja)

B. Cara Masuk ke Dalam Shell Container Terlebih Dahulu:
   docker exec -it pbl_database bash
   # Setelah masuk ke root container, ketik:
   mysql -u root -p pbl_db
   # Masukkan password: passwordkuat123

C. Cara Cepat Satu Baris (Langsung Terbuka):
   docker exec -it pbl_database mysql -u root -ppasswordkuat123 pbl_db

# Query penting di dalam MySQL:
SHOW TABLES;
SELECT id, username, email, role FROM users;
SELECT * FROM sensor_data ORDER BY id DESC LIMIT 5;

# Mengurutkan ulang ID tabel users:
SET @count = 0;
UPDATE users SET id = (@count := @count + 1) ORDER BY id;
ALTER TABLE users AUTO_INCREMENT = 1;

# Simulasi Bencana (Hapus Database untuk Uji Auto-Restore):
DROP DATABASE pbl_db;

# Keluar dari MySQL:
exit;
