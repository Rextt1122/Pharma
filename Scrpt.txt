- Node 2 (Database MySQL 8.0):
  docker -H tcp://127.0.0.1:2376 ps

- Node 3 (Mosquitto MQTT Broker):
  docker -H tcp://127.0.0.1:2377 ps

- Node 4 (Disaster Recovery Watcher):
  docker -H tcp://127.0.0.1:2378 ps

Restart Layanan:
- Restart backend FastAPI:
  docker restart pbl_backend

- Restart / sinkronkan ulang seluruh 4 node:
  bash start-nodes.sh

- Cek log proses backend:
  docker logs --tail 30 -f pbl_backend


3. DATABASE MYSQL CLOUD
Masuk Langsung ke MySQL Database:
docker -H tcp://127.0.0.1:2376 exec -it pbl_database mysql -u root -pfabian100607 pbl_db

Query Penting di MySQL:
SHOW TABLES;
SELECT id, username, email, role FROM users;
SELECT id, suhu, kelembapan, kadar_gas, cahaya, status, created_at FROM sensor_data ORDER BY id DESC LIMIT 5;
exit;

Simulasi Disaster Recovery (Uji Coba Auto-Restore 4 Detik):
- Hapus database pbl_db:
  docker -H tcp://127.0.0.1:2376 exec pbl_database mysql -u root -pfabian100607 -e "DROP DATABASE pbl_db;"

- Pantau watcher memulihkan database secara otomatis:
  docker -H tcp://127.0.0.1:2378 logs --tail 15 pbl_backup


4. SIMULATOR & PENGUJIAN TELEMETRI SENSOR
Menjalankan Simulator Python Interaktif:
cd /home/azureuser
python3 scripts/simulator.py

Tombol Kontrol Simulator:
- p + Enter : Buka / Tutup Pintu (Reed Switch)
- g + Enter : Gerakan Orang Terdeteksi (Sensor PIR)
- u + Enter : Saklar Lampu UV-C Sterilisasi
- b + Enter : Saklar Sirine Alarm Bahaya
(Tekan Ctrl + C untuk keluar dari simulator)

Kirim Payload Sensor Sekali Tembak (Mosquitto CLI):
- Simulasi Kondisi Normal (Suhu 4.4 C, Cahaya 160 Lux):
  mosquitto_pub -h 127.0.0.1 -t 'pharma/sensor' -m '{"device_id":"device_1","suhu":4.4,"kelembapan":46.0,"kadar_gas":8.5,"cahaya":160.0,"status_pintu":0,"status_uv":0}'

- Simulasi Peringatan Suhu Hangat (Suhu 9.6 C, Cahaya 220 Lux):
  mosquitto_pub -h 127.0.0.1 -t 'pharma/sensor' -m '{"device_id":"device_1","suhu":9.6,"kelembapan":58.0,"kadar_gas":14.0,"cahaya":220.0,"status_pintu":0,"status_uv":0}'

- Simulasi Bahaya Gas & Pintu Terbuka (Gas 65 PPM, Cahaya 750 Lux):
  mosquitto_pub -h 127.0.0.1 -t 'pharma/sensor' -m '{"device_id":"device_1","suhu":5.1,"kelembapan":49.0,"kadar_gas":65.0,"cahaya":750.0,"status_pintu":1,"status_uv":0}'

Memantau Aliran Pesan MQTT Live (Listening Mode):
mosquitto_sub -h 127.0.0.1 -t 'pharma/#' -v
(Perintah diam menunggu pesan masuk. Tekan Ctrl + C untuk keluar)

7. PENJELASAN TEKNIS (JAWABAN PENGUJI / DOSEN)
Arsitektur Web Dashboard:
Dibangun sebagai Lightweight Embedded SPA (HTML5, Modern CSS, Vanilla JS ES6+) yang dilayani langsung oleh FastAPI. Tidak membutuhkan Node.js runtime terpisah di server sehingga RAM kontainer sangat hemat (~41 MB), waktu pemuatan instan (LCP < 0.5 detik), dan terintegrasi langsung dengan WebSocket MQTT serta REST API.

Perbedaan Web Dashboard dengan Aplikasi Flutter:
Aplikasi Flutter Android adalah client mobile operasional bagi teknisi dan staf lapangan untuk monitoring telemetri real-time, menerima peringatan darurat, dan mengendalikan saklar saat di gudang. Web Dashboard adalah konsol admin pusat di browser untuk manajemen akun user (tambah/edit/hapus staf), simulasi pengujian data IoT, inspeksi REST API, serta unduh rekap CSV.

Alasan Memilih FastAPI dibanding Laravel:
FastAPI berbasis asynchronous native (ASGI Uvicorn) dengan latensi respons < 10 ms, konsumsi RAM hanya ~41 MB (Laravel butuh 150-250 MB), serta integrasi MQTT (paho-mqtt) berjalan langsung dalam satu proses tanpa butuh queue worker atau Supervisor terpisah.

Alasan Memilih Database MySQL dibanding Firebase / NoSQL:
Kepatuhan ACID menjamin data pemantauan vaksin tidak korup, struktur relasi tabel akun dan telemetri terorganisasi rapi, penghitungan agregasi statistik dan ekspor CSV cepat lewat query SQL native, serta proses restore otomatis bencana selesai dalam 4 detik.

Alasan Memilih Self-Hosted VPS Azure dibanding Firebase / Ngrok:
Kedaulatan dan privasi data farmasi tersimpan di server privat sendiri, kontrol penuh implementasi 4-node Docker DinD untuk evaluasi DevOps, penggunaan protokol standar MQTT TCP port 1883 tanpa beban SDK berat, serta alamat domain dan IP publik permanen tanpa risiko sesi tunnel terputus.
