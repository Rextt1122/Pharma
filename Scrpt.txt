[6] PENGUJIAN TELEMETRI SENSOR & SIMULATOR HARDWARE ESP32-S3
--------------------------------------------------------------------------------

A. Menjalankan Simulator Otomatis & Interaktif (ESP32-S3 Node 1 & Node 2):

   # Jalankan di terminal VM:
   cd /home/fabian/pbl-project
   python3 scripts/simulator.py

   # Atau jalankan di terminal Laptop (Windows):
   uv run --with paho-mqtt python scripts/simulator.py

   # Tombol Cepat Keyboard saat simulator berjalan:
   #  p + Enter : Buka / Tutup Pintu (Simulasi Reed Switch)
   #  g + Enter : Simulasi Gerakan Manusia (Sensor PIR)
   #  u + Enter : Nyalakan / Matikan Sinar UV-C
   #  b + Enter : Nyalakan / Matikan Sirine Buzzer Alarm
   #  (Atau pencet tombol langsung di aplikasi Flutter di HP!)

B. Kirim Payload Sensor Manual Sekali Tembak:

   # Node 1 (Rak Penyimpanan):
   docker -H tcp://127.0.0.1:2377 exec pbl_mqtt mosquitto_pub -h 127.0.0.1 -t 'pharma/sensor' -m '{"device_id":"device_1","suhu":4.2,"kelembapan":45.5,"kadar_gas":8.0,"status_pintu":0,"status_uv":0}'

   # Node 2 (Keamanan & Sterilisasi):
   docker -H tcp://127.0.0.1:2377 exec pbl_mqtt mosquitto_pub -h 127.0.0.1 -t 'pharma/sensor' -m '{"device_id":"device_2","status_pintu":0,"deteksi_gerak":0,"jarak_stok":20.5,"status_uv":0}'
